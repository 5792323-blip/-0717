# 策略0717程序功能索引

这是项目的总入口。根目录只保留资料和功能文件夹，Python 程序已经按用途归类。

## 最常用的三个入口

| 要做什么 | 程序 | 命令 |
|---|---|---|
| 打开参数回测页面 | `运行程序/interactive_backtest_app.py` | `python3 -m 运行程序.interactive_backtest_app --host 127.0.0.1 --port 8501 --no-open` |
| 运行单股或多股回测 | `运行程序/run_backtest.py` | `python3 运行程序/run_backtest.py --help` |
| 自动执行“诊断→优化” | `运行程序/auto_runner.py` | `python3 -m 运行程序.auto_runner --help` |

日常只需要先看 `运行程序/`。研究新因子时再进入 `研究实验/`，分析亏损原因时进入 `分析工具/`。

| 文件夹 | 功能 | 是否日常使用 |
|---|---|---|
| `1_策略配置/` | 正式策略参数和所有模块开关 | 是，谨慎修改 |

| `5_买入规则/` | 4种RSI买入条件，每种一个小程序 | 策略积木 |
| `6_卖出规则/` | ATR、止损、止盈、时间退出等 | 策略积木 |
| `7_仓位管理/` | 单股和总仓位控制 | 策略积木 |
| `8_过滤因子/` | 买入前过滤条件 | 策略积木 |
| `因子模块/` | 可选扩展因子和机器学习接口 | 实验积木 |
| `模块系统/` | 中央开关、模块校验和独立调用 | 基础设施 |

| `11_策略文档/` | 策略设计、实验结论和决策说明 | 查阅使用 |

## 安全规则

- 页面回测只复制正式配置到实验目录，不直接覆盖 `1_策略配置/`。
- `9_输出/` 与 `10_实验记录/` 是结果，不是策略源程序。
- 标记为“未就绪”的机器学习模块不能启用。
- 修改核心程序后运行：`PYTHONPATH=. pytest -q`。

每个新整理的程序文件夹内还有自己的 `README.md`，列出该目录全部程序的用途。
