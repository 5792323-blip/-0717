## 三、核心买入机制 — 哨兵价体系（最重要）

### 3.1 哨兵价是什么

哨兵价是本策略的**核心创新**，解决了"RSI上穿后何时买入"的问题：

- 传统做法：RSI上穿阈值 → 下一根开盘买入（可能已经反弹很多）
- 哨兵价做法：RSI上穿 → **反推一个目标价位** → 价格突破该价位才买入

### 3.2 哨兵价形成流程

```
① RSI上穿检测 (本根收盘RSI > 阈值 且 上一根RSI <= 阈值)
    阈值优先级: 20 > MA(均线) > 30 > 70
        ↓
② 反推价计算 (用最近15根前复权收盘价反推)
    目标: 找到"如果RSI回到阈值时，价格应该是多少"
    哨兵价 = max(反推价, 上一根K线最高价)
        ↓
③ 哨兵价形成候选 (标记为"已形成，待突破")
    哨兵价只允许向上跟踪，不可回退
        ↓
④ 突破成交 (本根最高价 > 哨兵价)
    本根形成立即成交模式: 同一根K线形成并成交
    成交后"消费"当前档位，哨兵价数值保留继续向上跟踪
```

### 3.3 核心模块开关（6个）

| 模块 | 启用 | 说明 |
|:--|:--|:--|
| 反推价计算 | ✅ | 根据历史前复权收盘价反推目标RSI对应价格 |
| 哨兵价形成 | ✅ | 分别保存RSI反推价和上一根最高价 |
| 哨兵价突破成交 | ✅ | 本根同时达RSI反推价且严格突破上一根最高价后买入 |
| 哨兵价突破后上移 | ✅ | 价格突破但未成交时允许哨兵价跟随上移 |
| 本根形成立即成交 | ✅ | 本根哨兵价形成后用本根最高价立即检查成交 |
| 下一根执行 | ❌ | 使用事先已计算的反推价（关闭，改用本根成交）|

### 3.4 买入时机模式

当前模式: `same_bar_entry`（本根形成哨兵价后立即成交）

| 模式 | 说明 | 当前 |
|:--|:--|:--|
| STRICT_PRECOMPUTED | 用上一根RSI预计算哨兵价，本根最高价突破即成交 | 备选 |
| SAME_BAR_ENTRY | 本根收盘RSI确认上穿，本根最高价突破即成交 | ✅ 当前 |
| CLOSE_NEXT_OPEN | 收盘价确认突破后，下一根开盘执行 | 关闭 |

## 六、卖出规则详解（12个，仅1个启用）

### 6.1 当前启用

| 规则 | 说明 | 当前参数 |
|:--|:--|:--|
| ✅ ATR跟踪止盈止损 | 价格从最高点回落2.5倍ATR时卖出，MA动态调整 | ATR倍数=2.5, MA调整倍率=50, 下限比例=0.6 |

### 6.2 ATR跟踪退出算法（当前唯一启用的退出）

```
跟踪线 = 参考价 - 有效倍数 × ATR
参考价 = 最高价（持仓期间最高价）

MA动态调整:
  MA下降时(防震): 有效倍数 = ATR倍数 × (1 + |MA斜率| / MA调整倍率)  → 放大
  MA上升时(锁利): 有效倍数 = ATR倍数 × max(下限比例, 1 - MA斜率 / MA调整倍率)  → 缩小

触发: 当前价格 < 跟踪线 → 卖出
ATR缺失容错: 用 买入价 × 0.02 代替
```

### 6.3 全部卖出规则清单

```

  检查顺序: 0 → 1 → 2 → 3 → 4 → 5 → 6
  任一触发 → 执行卖出（支持部分卖出）
```

### 6.5 卖出执行细节

```
卖出价 = min(开盘价, 触发价) × 不复权/前复权比率 × (1 - 滑点)
交易费用: 佣金 + 印花税(万5) + 过户费
连续亏损3次 → 冷却期10根K线
盈利一次 → 清零连续亏损计数
```

### 7.1 基准仓位

| 参数 | 值 | 说明 |
|:--|--:|:--|
| 初始资金 | 20,000,000 | 2000万 |
| 基础单只金额 | 200,000 | 每只基础20万 |

| 最大总持仓数 | 200 | 最多同时持有200只 |
| 最大总仓位比例 | 98% | 总仓位不超过98% |
| 现金底线 | 20% | 永远留20%现金 |

### 7.2 仓位计算公式

```
买入金额 = 基础单只金额 × 信号质量分 × 大盘系数 × 波动率调整

三重上限约束:
  1. 金额 ≤ 单只上限 (10% × 总资金)
  2. 金额 ≤ 当前现金 × 20%
  3. 金额 ≥ 0
```

### 7.3 大盘系数（4种状态）

| 状态 | 系数 | 条件 |
|:--|--:|:--|
| 进攻模式 | 1.0 | 大盘在120日均线上方 且 20日线向上 |
| 震荡模式 | 0.5 | 不满足进攻也不满足防守 |
| 防守模式 | 0.2 | 大盘在120日均线下方 且 20日线向下 |
| 收缩模式 | 0.3 | 市场平均ATR > 前20日ATR × 1.5（高波动，覆盖其他状态）|

### 7.4 波动率调整

| 波动率 | 调整 | 阈值 |
|:--|--:|:--|
| 高波动 | 仓位打7折 | 年化波动率 > 40% |
| 正常 | 不调整 | 20% ~ 40% |
| 低波动 | 仓位加1.2倍 | 年化波动率 < 20% |

### 7.5 总仓位控制

```
目标仓位比例 = 0.98 × 大盘系数
拦截条件:
  - 剩余配额 ≤ 0 → 不允许买入（资金满仓）
  - 剩余持仓数 ≤ 0 → 不允许买入（持仓数满）
```

## 十、回测引擎

```

  2. 初始化规则执行器 (加载所有配置)
```

### 11.2 哨兵价买入决策树

```
RSI上穿检测
├─ RSI上穿20 (优先级0) ──→ 反推价 = 反推(RSI=20)
├─ RSI上穿均线 (优先级2) ──→ 反推价 = 反推(RSI=RSI_MA)
├─ RSI上穿30 (优先级1) ──→ 反推价 = 反推(RSI=30)
└─ RSI上穿70 (优先级3) ──→ 反推价 = 反推(RSI=70)
        ↓
哨兵价 = max(反推价, 上一根最高价)
        ↓
过滤因子检查 (13个, 当前仅RSI_MA过滤启用)
├─ 通过 ──→ 等待价格突破哨兵价
└─ 拦截 ──→ 不买入
        ↓
本根最高价 > 哨兵价?
├─ 是 ──→ 执行买入
│         ├─ 成交价 = 哨兵价 × 买入溢价(1.001)
│         ├─ 仓位 = 基础20万 × 质量分 × 大盘系数 × 波动率
│         ├─ 费用 = 佣金 + 过户费
│         └─ 记录买入
└─ 否 ──→ 哨兵价向上跟踪, 等待下一根
```

## 十三、当前策略特点总结

### 13.1 当前运行策略的本质

```
极简基线配置 = 哨兵价突破体系 + 4个RSI买入信号 + RSI_MA过滤 + ATR跟踪退出 + 网格加仓
```

### 13.2 策略优势

1. **哨兵价体系**：避免RSI上穿后追高，等待价格确认才买入
2. **双价格体系**：前复权算指标，不复权成交，逻辑清晰
3. **模块化设计**：所有规则配置化，改yaml不改代码
4. **ATR动态退出**：MA方向动态调整跟踪宽度，防震又锁利
5. **多维度仓位**：信号质量 × 大盘 × 波动率 三重调整

### 13.3 当前局限

1. **极简配置**：13个过滤因子仅1个启用，12个卖出规则仅1个启用
2. **无ML模型**：4个机器学习模块全部未就绪
3. **单一退出**：仅ATR跟踪退出，无止损/止盈/时间退出保护
4. **数据源风险**：依赖闲鱼第三方卖家，非官方数据源

### 13.4 待开发方向

| 方向 | 优先级 | 说明 |
|:--|:--|:--|
| 启用硬止损 | 高 | 当前无止损保护，风险较大 |
| 启用分批止盈 | 高 | 锁定利润 |
| 启用大盘状态过滤 | 中 | 防守期减少操作 |
| ML模型训练 | 中 | LightGBM/XGBoost预测器已就绪 |
| 委员会投票 | 低 | 多模型协同决策 |
