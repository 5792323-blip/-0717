# 个股基本面数据接入说明

## 当前阶段

项目暂不直接抓取某个商业数据源，也不把当前财报值回填到历史回测。请从同花顺、iFinD、Tushare 或其他已授权数据源导出 CSV，再使用导入器写入项目快照。

## 导入命令

```bash
python3 基本面/导入个股基本面快照.py your_export.csv --check-only
python3 基本面/导入个股基本面快照.py your_export.csv
python3 基本面/审计个股评分数据.py 数据模块/基本面历史快照.csv
python3 基本面/计算个股评分.py 数据模块/基本面历史快照.csv
```

导入器会：

- 统一常见中文和英文列名；
- 计算自由现金流和 `FCF净利比`；
- 按 `股票代码 + 实际披露日` 去重；
- 拒绝披露日晚于评分日的数据；
- 默认写入 `数据模块/基本面历史快照.csv`，不覆盖原始导出文件。

## 最小可用字段

必须提供：`股票代码`、`实际披露日`、`评分日期`。

正式评分还需要尽量补齐：`ROE`、`ROIC`、`收入3年CAGR`、`扣非净利润3年CAGR`、`资产负债率`、`利息保障倍数`、`PE_TTM`、`PB_MRQ`、`EV_EBITDA`、`FCF_Yield`。

## 重要规则

报告期末不是可用日期。比如 2025 年年报的报告期是 2025-12-31，但只有在实际披露日之后才可用于评分。没有实际披露日的数据只能用于当前研究展示，不能进入严格历史回测。

数据覆盖率达到要求并完成小样本对照回测前，继续保持 `fundamental_universe_filter` 关闭。

评分结果写入 `基本面/个股评分结果.csv`，包含五维分数、各维度覆盖率、总分、置信度、硬风险和准入结论。输入文件不存在时，评分器会直接停止，不生成示例评分。

## 一键联合管线

```bash
python3 基本面/联合评分管线.py
```

管线会依次审计 v3 当前台账、审计个股快照、生成个股评分、生成行业历史评分并审计联合模块是否可启用。任一步骤未就绪都会返回失败并写入 `基本面/运行记录/联合评分管线报告.json`，不会自动打开过滤器或用当前值回填历史。
