# 行业景气严格回测数据格式

`行业景气评分历史模板.csv` 每一行代表某行业在**生效日期**已经可以获得的评分。`数据截止日` 不能晚于 `生效日期`；若评分基于季报，应使用实际披露日而非报告期末。

`股票行业归属历史模板.csv` 每一行代表某只股票自**生效日期**起采用的行业归属。行业名称必须与评分文件完全一致；不能以当前分类回填过去。

`导入申万历史行业归属.py` 可从公开申万历史变动源下载原始记录，保存为 `申万股票行业变动_raw.csv`。该源只提供行业代码，因此脚本会先生成 `申万行业代码映射待补清单.csv`；只有 `申万行业代码映射.csv` 对全部代码完成核验后，才会生成可供回测读取的 `股票行业归属历史.csv`。映射模板见 `申万行业代码映射模板.csv`。

行业景气过滤器仅允许 `生效日期 <= 交易日` 的最新记录。行业归属或评分缺失时，禁止新开仓；已有持仓仍由原有卖出、止损和网格管理规则处理，不会被行业过滤器直接平仓。

## 个股基本面历史回测

`数据模块/基本面历史快照.csv` 必须包含每个股票多个评分日期，并且每条记录满足：`实际披露日 <= 评分日期`、`数据截止日 <= 评分日期`。关键指标覆盖率至少90%，股票覆盖至少288只，评分日期至少4个。使用 `基本面/审计个股历史基本面.py` 审计；未通过时，主页会阻止开启基本面评分历史回测。
