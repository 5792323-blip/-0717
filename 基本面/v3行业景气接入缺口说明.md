# v3 行业景气接入缺口

## 当前审计结论

当前工作簿的 `指标更新台账_v3` 有 525 个指标、覆盖 43 个行业，但这些内容目前属于“当前台账展示值”，还不是严格回测数据：

- 当前值和当前评分虽然有填充，但全部数据状态仍是“待更新”；
- 没有任何数据发布日期；
- 历史指标评分文件目前只有“综合|制造业PMI”序列；
- 因此不能据此生成 31 个一级行业的历史景气评分，也不能打开联合过滤器。

## 正确接入方式

### 当前研究/实时使用

补齐每个指标的：

- 当前原始值；
- 指标评分；
- 实际发布日期；
- 数据截止日；
- 数据来源和来源优先级；
- 数据状态。

只有通过这些字段的审计，才能生成当前行业景气快照。

### 历史回测使用

必须把每个指标保存成历史记录：

```text
指标键,生效日期,数据截止日,指标评分,来源,来源优先级,评分版本,备注
```

并满足：

- `数据截止日 <= 生效日期`；
- 行业核心指标覆盖率达到 90%；
- 31 个一级行业均有评分；
- 缺失行业或缺失时点不能用当前值回填。

## 与个股评分的结合

两套体系最终通过以下关系接入：

```text
行业景气评分 40% + 个股基本面评分 60% = 联合评分
```

联合评分只影响新开仓准入和仓位系数，不改变 RSI、哨兵价、网格和卖出执行。
